# learn-genai.in — idea brainstorm

Working name: **learn-genai.in**

Tagline in use: **Prompt the Next Era.**

The platform is free for every learner. There is no paid tier, no seat limit, and no certificate for sale. Learners do not need an account. Only an admin signs in.

## Who it is for

- **Students.** Final year, a placement drive on the calendar, and a chat tool they are afraid to use in the wrong room.
- **Software engineers.** A teammate's repo, a failing test, and a review that will ask them to change one line.
- **Founders.** A Thursday demo. The product has to work, and they have to explain the part a model drafted.

The same need runs through all three: use generative AI on real software work, and still be able to explain it with the chat closed.

## What the product is

One free path, not a course catalog and not a six-product suite.

1. Read a lesson.
2. Watch the video if an admin has filmed that lesson.
3. Answer two checks.
4. Try one prompt and compare the reply with what a good reply looks like.

The shape of an ordered path, where each stop says what it assumes, comes from reading the public pages of vizuara.ai (home, courses, books roadmap, pods path, bundle, research, and related product sites). The writing, the audience, and the layout are original. App code is not part of this note.

## The six stops

Each stop says what the learner already needs to know. Anyone can drop in where that sentence is already true. Campus placement rules appear where a proctored test is the room. The same closed-chat habit applies to code review and a customer demo.

1. **The work.** Where a coding assistant belongs: a placement test, a code review, or a customer demo.
2. **How a chat behaves.** The model only sees the text in the window. A confident reply can still be wrong.
3. **The tool shelf.** ChatGPT, Claude, Gemini, GitHub Copilot, and Cursor. What each one is for, and when to leave it closed.
4. **On the work.** Read a small repo. Debug a failing test. Run the hypothesis yourself.
5. **Say it live.** Explain code you did not type first. Tell a project story with a user, a constraint, a check, and a limit.
6. **The lines.** Proctored tests, campus notices, keys, private repos, and other people's assignments stay out of the chat.

## Read, understand, be taught

- **Read.** Walk the six stops.
- **Understand.** Open the tool shelf and pick one tool for the job.
- **Be taught.** Watch the short video an admin attached to that lesson, then do the checks and the prompt.

If a lesson has no video yet, the reading still stands. Watch appears only when a video is published.

## Admin

The admin signs in, uploads a video (mp4, webm, or mov), and attaches it to a lesson.

- Publishing makes the video free on that lesson and on a Watch page.
- Hiding it removes it from the learner site without deleting the reading.
- Learners never see a price.

Prototype sign-in, for the local build only: `admin@learn-genai.in` / `learn-genai`.
