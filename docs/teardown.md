# Pattern teardown (October 2026)

Evidence gathered from each live site in a browser: page structure, headings, calls to action, type and stack. Patterns were borrowed; no code, copy, imagery or branding was copied.

| Site | What it does well | What we took |
|---|---|---|
| **Vizuara** (vizuara.ai) | Vite + React SPA. Announcement bar, mega-menu, search-first hero, a hub diagram linking every offer, F→P→R method in three numbered cards, animated impact counters, course library with a "what you get" tick list, corporate section, newsletter. | Announcement bar, mega-menu, search-first hero, hub diagram, three-step method, counters, library + includes list, newsletter. |
| **Scaler** | Outcome-first headline, "find the path for your role", proof-heavy ("proof matters more than empty promises"). | Seat picker (Students / Engineers / Founders) and outcome-first copy. |
| **upGrad** | Trending programmes, "choose your area of interest", learner support, free-course funnel. | Filterable library and a free entry lesson as the main call to action. |
| **Physics Wallah** | "Trusted & affordable", exam categories front and centre, study resources. | Free-forever positioning stated as a number (₹0) and situation-based entry points. |
| **Duolingo** | "free. fun. effective." in three words; one dominant Get started button; streaks and motivation. | Playful system, one primary action per view, streak badge in the hub card, short lessons. |
| **DeepLearning.AI** | Course grid by track, clear "Start" on every card, learning tracks. | Lesson cards with stop, time, kind and a single action. |
| **Hugging Face Learn** | A plain, scannable course index. | Library grid that reads like an index, not a store. |
| **Linear** | Inter at 64px/510 with -1.4px tracking, generous whitespace, product shown not described. | Tight display tracking, section rhythm (96px), product UI (quiz, sandbox, tutor) shown live on the page. |

Blocked for automated reading in this session: Brilliant, Vercel, Khan Academy (page scripts).

## Where learn-genai.in wins

1. **The only one teaching judgement, not tools.** Others teach how to build with AI or sell exam prep; nobody teaches students how to *use* AI and still own their work.
2. **Two hours, free, phone-first.** Competitors sell months-long paid programmes.
3. **Built for the room the student is about to walk into:** placement drives, vivas, code reviews, demo days.
4. **A college channel** (placement cells) with a faculty view, which none of the consumer apps offer.
