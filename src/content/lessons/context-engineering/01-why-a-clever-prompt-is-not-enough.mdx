You write a careful prompt. It starts with "You are an expert", and it works well in a demo.

Then you build a real application around it, and the answers get worse. The prompt did not change. So what did?

## The prompt is one block

Every time you call a model, it reads a **context window**. The context window is everything the model can see in that one call.

In a demo, your prompt is almost the whole window. In a real application, the window also holds the system prompt, the tool definitions, the documents you retrieved and the conversation so far. Your prompt is one block among them.

## The window has a fixed budget

The window has a fixed size. The size is counted in tokens. A token is a piece of a word that the model reads. As a rough guide, one token is about three quarters of a word.

Everything has to fit inside that budget, and all of it is sent again on every call. So a clever sentence in your prompt cannot help much when the rest of the window is full of things the model does not need.

## A bigger window does not fix it

It is tempting to get a bigger window and put everything in it.

Researchers tested how models use long contexts. A model used the information at the start and at the end of a long context well. It missed more of what sat in the middle. The paper calls this "lost in the middle".
